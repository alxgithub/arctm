Controlo é o posto principal, com o número grande em cima. Comando encolhe o número a uma faixa e dá o ecrã todo aos cartões, com botões maiores — é o modo para andar com o telemóvel na mão. Só mostrar tira a barra e os botões: fica apenas informação para o público. Ligue a partilha em todos os aparelhos para andarem a par.
Servidor de mensagens (avançado)
Todos os ecrãs com o mesmo código veem os mesmos pedidos. Escolha um código difícil de adivinhar — a ligação passa por um servidor público de mensagens, sem contas nem registo. Funciona quando as aplicações estão alojadas por si; dentro do Claude, use a partilha por conta.
